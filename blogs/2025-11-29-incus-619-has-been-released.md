# Introduction The Incus team is pleased to announce the release of Incus 6.19! This is a slightly less busy release than usual as we've recently been spending quite a bit of time smoothing some of the initial rough edges from the [IncusOS release](https://discuss.linuxcontainers.org/t/announcing-incusos/25139). That said, it still contains quite a few nice improvements and quite a lot of bugfixes!
